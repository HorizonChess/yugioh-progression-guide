# Documentation Rules

1. **Update README.md**: Whenever you add a new major feature (e.g., a new page, a new core mechanic) or significantly modify an existing one, you MUST update web/README.md to reflect the changes.
   - Update the 'Architecture Overview' if you add new routes or components.
   - Update 'Key Features' if you add new functionality.
2. **Keep it Sync**: Ensure the documentation accurately reflects the current code. If you change a folder structure, update the README immediately.
